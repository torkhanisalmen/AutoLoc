# AutoLoc

## Description du projet

AutoLoc est une application de gestion de location de véhicules.

L'objectif du projet est de permettre aux clients de rechercher et réserver
des véhicules, tout en permettant aux agences de gérer leurs véhicules,
leurs locations et leurs utilisateurs.

## Acteurs

Le système AutoLoc comprend les acteurs suivants :

- Client
- Agent d'agence
- Responsable d'agence
- Administrateur

## Acteur : Client

Le client peut notamment :

- Consulter les véhicules disponibles
- Rechercher un véhicule
- Consulter les informations d'un véhicule
- Effectuer une réservation
- Consulter ses réservations
- Annuler une réservation

## Acteur : Agent d'agence

L'agent d'agence peut notamment :

- Consulter les réservations
- Gérer les locations
- Enregistrer le départ d'une location
- Enregistrer le retour d'un véhicule
- Consulter les informations des clients

## Acteur : Responsable d'agence

Le responsable d'agence peut notamment :

- Gérer les véhicules de l'agence
- Consulter les locations
- Superviser les agents
- Consulter les informations de l'agence

## Acteur : Administrateur

L'administrateur peut notamment :

- Gérer les utilisateurs
- Gérer les agences
- Administrer les véhicules
- Gérer les paramètres du système
